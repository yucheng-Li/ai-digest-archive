## 官方博客

### Anthropic Engineering：Redesigning source control at Anthropic
作者：Nick G. 与 source control 团队

Anthropic 放弃了 git。他们自研了一套叫 **Scion** 的版本控制系统，并在**五个月内**把整个 monorepo 从 git 完整迁移过去，同时还顺手建了代码审查工具 Antique、代码搜索和一整套源码权限体系 —— 全程只有**七个人**。

逼出这件事的数字很吓人：2026 年 5 月，Anthropic 平均每天合并约 2,500 次代码变更；到 9 月，这个数字变成**每天 3 万次以上**。主分支历史接近 100 GB，压缩后的工作副本超过 25 GB，光 CI 每天就要做 2,500 万次 checkout —— 如果老老实实用 git 拉取，每天的流量会超过 600 PB。他们曾经同时运维几百个内部 git 镜像来扛，最后还是扛不住。

核心洞察非常干脆：git 为"离线、去中心化"而设计，但 Anthropic 的客户端几乎全是**永远在线的 agent 和 job**，git 最引以为傲的那些特性反而成了扩展性的敌人。于是 Scion 反过来做 —— 服务端负责 commit、merge、rebase、blame、history，客户端只维护一个有界的本地缓存；所有源码查询都开放成 API，CI job 根本不需要本地仓库。

结果：源码基础设施的 CPU 和内存开销比原来的 git 镜像方案**小 200 倍**，CI 和研究任务的 checkout 从分钟级降到秒级，单是 CI 就省出 **25% 的 CPU 容量**。

几条给所有团队的真实启示：
- Claude 把他们手写的 git→Scion 摄取管线整个重写了一遍，**内存占用降到 1/20、速度快 4 倍**，而且完整保留了所有隐式不变量。
- 工程师的价值没有下降，但工作内容变了。原文最精辟的一句：**"很多时候，工程师的角色就是对 Claude 说'不'。"** agent 会为了满足一个本来就不该存在的模式而破坏系统核心约束。
- 他们在 Slack 里养了一批叫 **"superfan"** 的 Claude —— 一个只盯 scion-daemon，一个只盯 scion-cache，一个只盯 Antique 合并队列，接入全部遥测和日志，像一个闲得只会刷监控图找异常的资深工程师。他们的评价是：superfan 能发现那些让传统告警显得"很一维"的微妙新型问题。
- 最颠覆的一条：**在 agent 规模下，merge queue 这个东西本身可能不成立。** 当测试还在跑的时候就有几百上千个变更合进来了，CI 到底还意味着什么？他们放弃了全局仓库锁，转向合并后和部署前的自动化测试，理由是"冲突发生时，Claude 修好它通常比人类发现它还快"。

Anthropic 明确说 Scion 不会开源也不适合大多数公司（"Scion 绝不是 git 的通用替代品"），但判断这类问题会在**未来 6 到 12 个月**变得普遍，所以选择把思路公开，和 GitHub、GitLab 及开源社区一起改进 git 服务端架构。

### Training Data：David Silver and Lasse Espeholt of Ineffable Intelligence: A Superlearner for the Age of Experience

**核心观点：通往超级智能的捷径不是堆更多互联网文本，而是彻底放弃它。**

两位嘉宾都是 DeepMind 老将。David Silver 2009 年的博士研究就是用 RL 下围棋，后来主导了 AlphaGo、AlphaGo Zero 和 AlphaZero，是第一个把 RL 做到超人类水平的人，启发了整整一代深度强化学习研究者。Lasse Espeholt 是他多年的搭档，写出了 IMPALA 和 SeedRL 这两套奠基性的分布式 RL 架构，今天大规模 RL 训练的很多核心思路都能追溯到他当年的工作。两人和另外两位联创（四位联创都出自 DeepMind 的 AlphaStar 团队）离开 DeepMind 创办了 Ineffable Intelligence，现在手握 Google 最大 GPU 集群之一（Vera Rubin 架构）的首批使用权。他们专门提到 Vera Rubin 的一整个机架可以当成一台机器用、节点间带宽极高，这对迭代周期极快的 RL 来说比对相对慢得多的 LLM 训练重要得多。

最反直觉的一点：他们认为人类数据不是在帮 AI，而是在拖后腿。Silver 举了自己的例子 —— AlphaGo 带着人类棋谱迭代了两年，而彻底抛弃人类数据、完全自学的 AlphaZero **只用了四个小时就击败了国际象棋领域有史以来最强的 AI**，围棋也只花了几天。他对语言的判断更尖锐：认为"人类语言是推理的终点"这种想法有点天真，而且从人类语言出发本身就有问题，因为它会把我们关于"agent 该怎么思考"的全部偏见一起拖进来。他的类比很好懂：如果让 agent 只能使用一千年前或两千年前的人类语言，它可能会相信地球是平的、相信疾病是四种体液失衡导致的 —— 这些错误会因为深深嵌在语言和思维过程里而极难剔除。

所以 Ineffable 刻意不碰互联网文本，而是把 agent 扔进自己设计的模拟世界（他们称之为 **crucibles**，熔炉）。关键不是手工设计一堆谜题，而是让环境本身具备海量的涌现复杂度（比如数百万个物体交互的复杂物理引擎），只给极简单的目标，赌科学、数学、技术乃至语言会像人类文明史一样自己长出来。

Silver 的原话是：**"until we give up on relying on the trillion item datasets of human knowledge, that we're not going to make the progress that the field deserves to see."**（在我们放弃依赖那些万亿条目的人类知识数据集之前，这个领域不会取得它本该取得的进展。）他补充说这不是宗教式的教条，而是务实判断 —— 弱的、跨环境通用的先验完全可以接受，他们要避开的是那种强到把特定世界的全部知识都编码进去的先验。

最后是时间表。主持人称他为"super forecaster"（围棋、StarCraft、IMO 数学奥赛被攻克的时间点他都提前多年押中过）。他给的答案：**一年内会看到这条路走得通的极强证据；真正的超级智能，原本判断三到五年，现在因为 coding agent 在加速一切，收窄到三年。**
