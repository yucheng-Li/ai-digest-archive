### Claude Blog

**Claude Cowork and chat are now one Claude**

从今天起 Cowork 和 chat 合并。不管是一个快问快答，还是一份中午就要交的报告，都可以直接扔给 Claude——哪怕你已经合上笔记本它也会继续做。先在 Pro 和 Max 计划上滚动上线，Team 和 Free 随后，Enterprise 管理员会在任何变更前至少 30 天收到通知。

同时新增 Claude Docs 和 Claude Slides，Claude Design 也能在对话里直接用。要文档就和 Claude 一起写，要演示就让 Claude 起草 slides，可以直接编辑、直接演示，或者导出成 PowerPoint / PDF。三者都在付费计划上处于 beta，Enterprise 管理员自己决定何时开启。

合并的理由写得很直白：Cowork 原本是为"大活"单独开辟的地方，Design 是为视觉工作准备的，结果人们两个都在用，而最烦的部分是**判断一个任务该归到哪里**——而且在一边开的头带不到另一边去。"所以我们不再让你做这个选择。"现在 Claude 自己判断任务需要什么，Cowork 和 Design 的能力在任何一个对话里都能调用，并且带着你已有的上下文、skill 和 connector。

文中引用了 Senior Economist Andrew Keller 的使用场景："我可以让 Claude 调出我的法律研究数据库，它会把所有案例拉出来、读完、判断我还可能需要哪些案例、下载下来存到一个文件夹里等我审阅。"

实际形态是这样的：中午要交周报，出门前你问 Claude 上周 pipeline 有什么变化，再补一句"按我们一贯的写法写，把滑期的都标出来，重点做成五页 slides 给管理层会议用"。不清楚的地方 Claude 会问。路上可以用手机看进度，到工位时报告已经等在那儿了，slides 也能直接打开、调整、导出成 PowerPoint——因为出自同一个对话，slides 和报告本来就是对齐的。还可以设成每周一自动开始。

控制权部分：默认 Claude 在采取行动前会先问你；如果你更希望它一路做下去、只在需要仔细看的地方来找你，可以打开那个开关。最终决定权在你。
