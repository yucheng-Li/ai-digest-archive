### Claude Blog

**Claude in Chrome is generally available**

Claude in Chrome 正式 GA，所有付费 Claude 套餐都可用；更关键的变化是 Claude 现在能在浏览器里自主执行动作，不必每一步都等你点确认——每个动作执行前会过一道安全分类器，校验它是否安全、是否与你的原始请求一致。定位很明确：你每天用的很多工具已经接进了 Claude，但内部看板、遗留系统、供应商门户这些没接的，就交给浏览器——Claude 借你已有的登录态读页面、打字、点链接、翻页、填表。

从去年的 pilot 走到 GA，核心卡点一直是 prompt injection。Anthropic 这次给了三层防御和一组实测数字：模型本身持续用不断扩充的攻击库训练；probe 在 Claude 处理网页内容前先扫一遍 tool result，命中可疑内容就提醒模型保持怀疑、必要时回头问用户；以及与 Claude Code auto mode 同源的动作校验分类器，对不上你原始请求的动作直接拦掉。

数据上，早期那套评测已经被打穿（Fable 5 / Opus 5 / Sonnet 5 在 Cowork harness 下攻击成功率 0%，该评测已退役）。换成红队出品的更强攻击后：裸模型状态下 Opus 4.5 被攻破 17.6%，Opus 5 降到 3.8%；叠加 probe + 安全分类器后，Sonnet 5、Opus 5、Mythos 5 全部 0%，Fable 5 为 0.3%（已人工确认均为低危场景）。文章也没把话说满："Prompt injection 仍然是一个移动靶。"

实操提醒：从 Chrome Web Store 安装；企业版管理员可在 Organization Settings 里限制到已批准的域名；要操作本机文件或其他应用仍需桌面端；暂不支持其他 Chromium 浏览器和移动端。
https://claude.com/blog/claude-in-chrome-generally-available
