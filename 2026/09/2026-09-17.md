## 三、播客

### Training Data — Box's Aaron Levie: On Reinventing Yourself in the AI Age and Enterprise Diffusion

**核心观点**：模型越强，「应用层」反而越值钱——因为真正卡住企业的从来不是智能本身，而是把智能接进真实工作流的那一堆脏活。

Aaron Levie 二十年前创办 Box，做的是企业非结构化数据的存储、共享与管理，如今公司年化收入 13 亿美元，坐拥上千亿份文件。这个身位让他对「AI 到底怎么落地」有一种硅谷主流之外的视角：大部分人被 research 叙事拉着走，默认模型里的智能是唯一重要的形态；而他每天面对的是，就算给你世界上最强的超级智能，那个工作流依然需要连上别的数据系统，依然有人在环中的环节，依然有流程等待期让 agent 空转，依然有变革管理，依然有没现代化的遗留系统。

他对「为什么编程是 AI 扩散最快的领域」有一套很具体的拆解：写代码的价值创造几乎 100% 由能产出的文本量决定；模型在代码上被高强度训练；所有 AI Lab 都把编程当成竞赛基准，而且他们自己每天就在用；受众是史上最技术的一群人，agent 一报错他们自己就修了，不会打电话给 IT；而且这是个高薪垂直领域，哪怕只提升 10% 效率也立刻划算。把这几条拿去对照其他知识工作，差距一目了然——销售代表的价值创造是说服外部客户掏钱，就算给他最好的自动化，他依然被「客户回不回、有没有预算、周二能不能见」这些外部因素限流。

由此他给硅谷泼了盆冷水：AI 扩散会比你们想的慢得多。「编程领域有 GitHub，知识工作没有『把你的 GitHub 给我们』这种东西。」数据散落在本地系统、遗留文件共享、根本不会跟 agent 对话的企业环境里，权限结构也完全不同——工程师基本能拿到跟工作相关的所有东西，知识工作者却要挨个去申请访问权。

关于开源权重模型，他的回答很有层次：「比大家以为的高，比企业真正想要的低，比五年后的水平低得多得多得多。」他坦承现在有三成以上的采用动机纯粹是「想试试看」的新鲜感，但长期趋势成立——成熟的用例会被逐步剥离到开源模型上跑。这会造成一个让媒体困惑的局面：闭源厂商的收入在指数增长，开源权重的用量也在指数增长，因为编排用贵模型、长尾任务外包给便宜模型（或者反过来），两边花费可能各占一半，但 token 量能差十倍。

对做 SaaS 的公司，他给了一条不容含糊的双线要求：一边要把自家 agent 做到比通用 agent 在你的系统上强 10 到 20 个点，一边必须走 headless，把 API 通过 MCP 暴露给 Claude、ChatGPT 这些平台。他自己就是活例子：「我现在用 Salesforce 的频率比以前高了一个数量级，因为我通过 Claude MCP 连进去，一直在问我们 CRM 里的数据。」

最后是他对未来形态的一个硬预测：五年后，企业里 90% 的 token 都来自用户从未主动发起的任务——用户只是看到一个结果出现在那里，等着他去 review。

至于怎么保持在 AI 话题的中心，他的答案朴素到有点好笑：「我想给所有大二大三的学生发一条紧急通知——关注这 20 个账号，然后赶紧上 Twitter。你领先一年还是落后一年，完全取决于你的 feed。」
