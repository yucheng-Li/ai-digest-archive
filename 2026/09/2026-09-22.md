## PODCASTS

**No Priors — Coinbase's Everything Exchange: Agentic Finance, Stablecoins, and Tokenization with CEO Brian Armstrong**

**核心结论：** agent 经济的支付规模小到现有的信用卡体系根本吃不下——76% 的 agent 电商交易金额低于 30 美分，而刷卡的固定手续费就是 30 美分，这个缺口正在把 crypto rails 变成 AI 的必需品，而不是可选项。

说这话的是 Brian Armstrong，Coinbase 联合创始人兼 CEO，同时也是抗衰老公司 New Limit 的联合创始人。他现在给 Coinbase 押的三个方向是：Everything Exchange（股票、大宗商品、crypto、永续合约、预测市场全部上链，在同一个地方交易，共享流动性和跨品种保证金）、稳定币支付（即便 Bitcoin 价格下跌，这块业务依然在疯长，做到"一秒内、一美分以内、全球到账"），以及他称为 Agentic Finance / AIFi 的第三块。

Agentic Finance 最具体的一步是给 AI agent 开账户。"我们不希望 AI 是没有银行账户的群体——如果要给 AI 提供银行服务，它们也配拥有金融服务。"他们做了一套工具：把一段 prompt 粘进你的 agent，它就拥有了自己的自托管钱包和金融账户，绕开 KYC——毕竟 agent 没有政府签发的身份证，也没法走进银行网点（至少在有人形机器人分身之前还不行）。他们孵化的 X402 协议已经交给 Linux Foundation，Google、Cloudflare、AWS 都在一起推。那些几美分的交易在买什么？主要是信息：VC 从付费墙后面扒研究资料、招聘的人抓 LinkedIn 数据，更多是 agent 在向另一个专精 agent 买源数据，本质上就是一次 tool call。他的预判是市场上会长出大量专才 agent——用 10 万条合规审查案例微调过的小参数开源模型，在这个具体任务上能跑赢前沿模型。

内部这块他讲得更有意思：Coinbase 在追求某种"递归自我改进"。他们给公司、给每个团队、给每个代码仓库都建了一个"大脑"（今天就是一堆 markdown 文件）——里面装着这个服务历史上所有的事故、必须执行的财务管控、跑过的每一次 AB 测试、全部 PR 的接受与拒绝记录。agent 每次改动都先吃下这个大脑；关键在于人类 review 发现它漏了东西时，修正必须回写进大脑，而不是手动改完就发版。这样一次性通过的 PR 比例会随时间持续爬升。他们的内部 harness 叫 Toshi，已经能通过 X402 直接调用并支付外部供应商。连他这个 CEO 现在都能重新下场发功能：让一个贵模型把复杂功能拆成三个阶段、每阶段十件事，然后并行开十个 agent 去执行，还让它自己挑更便宜的模型——上播客前两分钟，系统提示他第一阶段十件事全部完成待 review。

对"公司会不会都变成十个人"这个流行论断，他明确不认同：被消灭的是任务，不是人。同样的团队会做得更多、更快，营收增速超过团队增速，毛利率会往上走。

其他数据点：Coinbase 88% 的营收已经来自非 Bitcoin 交易；预测市场上线数月内就跑到 1 亿美元年化营收，环比增速超过 100%；代币化股票产品是真正一比一由托管证券背书的证券，而非合成品或衍生品，目前仅在美国境外开放——他盯的是全球约 40 亿没有任何券商账户的人。

他自己下一步在想的"前沿问题"是认知增强：从儿童营养干预能提升 IQ 这条线索出发，考虑有没有办法在成人、儿童乃至胚胎层面把认知基线的起跑线拉平。"我们正在一场竞赛里。AI 越来越聪明，人类在某个时点也必须接管自己的进化，变得更聪明。"
