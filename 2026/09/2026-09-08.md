### No Priors：Rethinking Legacy Data Infrastructure — Eon 联创 Ofir Ehrlich & Gonen Stein

**The Takeaway**：企业最有价值的资产不是模型也不是算力，而是那些在磁带上积灰二十年的自有数据——模型和算力几乎零切换成本，数据才是真正的护城河。

Ofir Ehrlich 和 Gonen Stein 上一家公司 CloudEndure 被 AWS 收购，在 AWS 内部做的是应用迁移服务，亲历过成千上万台服务器上云的那一代基础设施迁移。现在他们做 Eon，把云备份/灾备重做成"AI 时代的数据底座"：先把散落在多个 hyperscaler 上的数据摸清、分类、打标，再低成本汇入统一底座，让企业能直接查询、搜索并把 LLM 跑在上面。

最硬的例子来自现实：Google 前不久从破产的 Spirit Airlines 手里买东西，买的不是飞机，是数据——花了 1000 万美元，为的是训模型；据说另一个竞标方是 Mercor。"如果你今天是一家有数据的公司的 CEO，你会不断被问：你愿不愿意卖你的数据？"他们还听说有实验室跑去华尔街，想从对冲基金手里买数据来理解和分析公司。原因很简单：真正像真实世界的数据集太难找了，合成数据一眼假。

安全那一段是全场最刺的。以前的威胁来自人，现在同样的威胁来自非人行为者："agent 拿着合法权限、合法访问环境，然后某张表突然就被 drop 了。"检测和恢复的方法论其实类似，但"发生的速度是极端的"。更麻烦的是非技术同事：市场、财务、法务的人用 Lovable 之类工具自己搭东西、把公司数据丢进去，他们的 agent 还会调别的 agent，而他们根本不懂这意味着什么——组织内部因此出现了一整批不受组织规则约束、也不跑在组织边界内、却在处理敏感数据的行为者。Gonen 的判断是：半年前没人愿意跟他聊这个话题，现在他见的每个企业负责人要么怕这事发生在自己头上，要么已经发生过了。

反直觉结论一条：dashboard 不会消失，反而会更多——因为在 agent 调 agent 调 agent 的世界里，那是唯一还能搞清楚"到底发生了什么"的方式。
