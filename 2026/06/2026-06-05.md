## 📝 Official Blogs

### Anthropic Engineering: How we contain Claude across products
Anthropic 公开了 claude.ai / Claude Code / Cowork 三大 agent 产品的"隔离架构"工程实践。核心观点：

- 12 个月前还无法接受让 Claude 拥有"足以拖垮 Anthropic 内部服务"的权限，今天这种权限已是常态——因为不部署的成本已超过部署风险
- Human-in-the-loop 在实际中不可靠：遥测显示用户对权限弹窗的批准率高达 **93%**，批准次数越多用户越麻木。这促成了 Claude Code **auto mode** 的诞生，可在执行前拦截约 **83%** 的过度行为
- 在 Gray Swan Agent Red Teaming 基准上，**Claude Opus 4.7** 单次 prompt injection 攻击成功率仅 **0.1%**，100 次自适应攻击成功率 **5-6%**
- "已审核的连接器 ≠ 已审核的数据"——一个通过 malware 检查的 GitHub 连接器仍可能把投毒的 README 直接灌入模型 context
- **Claude Mythos Preview** 因 blast radius 过高，于 2026 年 4 月被判定不能发布；防御体系成熟后才会逐步放开

链接：https://www.anthropic.com/engineering/how-we-contain-claude

## 🎙️ Podcasts

### No Priors × Lane Space: Microsoft CEO Satya Nadella —《全栈构建者与高杠杆通才的崛起》

**The Takeaway**: Nadella 抛出一个反直觉论点——**每家公司未来最大的 IP 不是模型也不是数据，而是"私有 eval"**。能在私有 eval 上替换底层模型 A→B 并继续爬坡的公司才掌握主动权；不能的公司则被模型供应商锁死。

Nadella 透露 Microsoft 过去 **15 个月**新增的 Azure 容量超过前 15 年总和。Azure 网络团队没有用扩招的方式应对，而是把工作"元化"：他们的新工作是**"构建一个做 Azure 网络的 agentic 系统"（代号 Miles）**，喊出"我们不需要 headcount，我们需要 token"。

他给 SaaS 时代的"终局"开了药方：底层数据模型（General Ledger、Power BI 语义模型）依然有价值不必重造，但要**解绑后用新方式重新打包**。M365 + WorkIQ 现在的使用密度，比 server 时代翻了 10-100 倍。

在编程领域，他坦言 "Coding 工作得太好，IDE 必须重建"——单 session 100 个 agent 的认知负荷已经回流到人身上，必须要 canvas、要新的 UI、要新的 review 流程。

定价模型上，Nadella 直言"客户嘴上要 outcome-based，真给他 outcome-based 又会反悔说是 royalty"——GitHub Copilot 已在重新加入"per-user + 消费计量"双轨。

教育是他认为下一个未充分释放的 AI 应用领域：**"下一个伟大的创业故事，可能是有人重造一所大学"**。
