### Claude Blog — New in Claude Managed Agents: dreaming, outcomes, and multiagent orchestration

Anthropic 一次性给 Managed Agents 发了三个大功能。

**1. Dreaming（研究预览）**：定时进程审阅过往 session + memory，提取模式、整理记忆，让 agent 跨 session 自我改进。能浮出单个 agent 看不到的东西——反复犯的错、agent 收敛出来的工作流、整个团队的共同偏好。可全自动写回 memory，也可人工 review 再落地。

**2. Outcomes**：用户写一份"成功长什么样"的 rubric，单独一个 grader（独立 context 窗口、不被 agent 推理污染）按 rubric 打分，不达标就让 agent 再来一遍。Anthropic 内部 benchmark 显示任务成功率最高 +10 个点，docx 生成 +8.4%、pptx +10.1%，最难的题提升最大。还支持 webhook 推送结果。

**3. Multiagent orchestration**：lead agent 拆任务派给一组带各自模型/prompt/工具的 specialist subagent，并行跑、共享文件系统，每个 agent 都记得自己干过啥，全过程可在 Claude Console 追溯。

实战案例很硬：Harvey 用上 dreaming，长文起草完成率提升 ~6 倍；Netflix 平台团队跑日志分析 agent，几百个 build 跨源并行；Spiral（Every 旗下）用 Haiku 当 lead、Opus 当 subagent，再用 outcomes 按编辑原则打分，只放符合标准的 draft；Wisedocs 文档质检 agent 用 outcomes 评分，审阅速度快 50%。

### The MAD Podcast with Matt Turck — State of Enterprise AI 2026: Aaron Levie on Tokenmaxxing, Rise of Headless, and AI-Proofing Your Job

**核心 takeaway**：模型进步反而拖慢了企业落地——上一版刚部署，下一版就让它过时。

Box CEO Aaron Levie 一年跟几百个 Fortune 500 / Global 2000 的 CIO 谈过，他说现在 enterprise AI 最热的桌面议题不是别的——**token 成本占了所有讨论的 1/3，有时是并列第一**。理由是这一年 agent 从 chatbot 模型（一问一答，被人类对话速度卡住）跳到能消耗 $1000 算力跑一个 task 的 coding agent，把"$20/seat/月"的订阅模型彻底打爆。

但他强调一个**反直觉点**——大企业的整体氛围其实是乐观的。CIO 看见自家工程师用 Cloud Code / Codex / Cursor 拿到了实打实的生产力增益，业务侧反过来在 pull："我也要用这玩意。"乐观但不天真：所有人清楚没免费午餐，token bill 来了就是要付的。

最重要的结构性观察：AI 预算正在**从 IT budget（占营收 3-7%）溢出到业务线 OpEx**。CMO 决定花一百万买 compute 还是办市场活动——这是新型决策，但 marketing 团队没有 FinOps，连"刚才那个 prompt 是不是花掉我一个月午餐补贴"都不知道。Levie 留了个明确的创业坑：

> "There's probably a $5,000,000,000 startup waiting to happen just in like ERP for your AI compute."

模型层会**分化（divergence）而不是收敛**：frontier 留给 coding / 高级生命科学 / 合同流程，task 一旦能稳定跑就剥到便宜模型甚至 OSS 模型。"普通企业未来会同时跑半打模型"——routing 层会是新的差异化护城河。还有一个反潮流提醒：有些场景根本不需要 agent，"你不会想让你的 agent 每天早上把 UI 重渲染一遍，每天花 $30 用界面"——deterministic software 还活着，跑在 CPU 上便宜得多。
