## 📝 官方博客

### Claude Blog — New in Claude Managed Agents: dreaming, outcomes, and multiagent orchestration

Claude Managed Agents 一次性放出三件大事：

- **Dreaming（研究预览）**：定时回看历史 session 和 memory store，提取反复出现的错误、收敛的工作流、团队共享偏好，自动整理记忆。可以全自动写入，也可以人工审核后落地。和 memory 配合，构成「跨 session 自我改进」的闭环。
- **Outcomes**：你写一个 rubric 描述「什么叫做好」，单独的 grader 在独立上下文里打分，agent 自动循环修正直到达标。内部基准提升任务成功率最多 10 个百分点；docx 文件生成 +8.4%、pptx +10.1%，越难的任务收益越大。配合 webhook，agent 跑完会主动通知你。
- **Multiagent Orchestration**：lead agent 拆任务、派发给各有自己 model / prompt / tools 的 specialist agent，适合超出单 agent 处理能力的工作。

## 🎙 播客

### Unsupervised Learning Ep 87 — Gemini Co-Lead on World Models, RL's Next Domains & Continual Learning

**The Takeaway**：在 Gemini co-lead Oriol Vinyals 看来，AGI 在某种程度上已经到了——只是「能否真正从经验中持续学习」才是下一个真正的门槛。

Oriol Vinyals 是 Google DeepMind 的核心研究者之一，和 Noam Shazeer、Jeff Dean 并列 Gemini co-lead。他对几个被反复争论的问题给了非常具体的回答：

- **World models 的「GPT 时刻」还没到**：能把视频/图像里所有重力、因果、动力学规律纯无监督抽出来，这个目标依然在研究阶段。Omni 是目前最强的多模态配方，但「不依赖语言只从视觉数据中提炼概念」这件事还在远处。

- **Memory 的形态会是文件系统，而不是权重**：「我们试图在大规模下只服务一个模型，让一个模型对不同用户带不同 memory 在工程上非常痛苦。」所以 continual learning 更可能落在 agent 写文件、读文件、配合简单检索机制的形式上，而不是 per-user fine-tune 权重。这正是「skills」「knowledge base」类机制在过去一年迅速崛起的原因。

- **Bitter Lesson 还会再吃一波 scaffold**：今天人们花大力气搭的 multi-agent、sub-agent、delegation 复杂系统，未来很可能由模型自己根据任务**即时生成**——「最 token 高效、最高质量的 sub-agent 配置」会是模型自己决定的，而不是工程师预编排。

- **RL 的下一个领域**：纯 verifiable 域（code/math）能产生明显泛化，他对此「没想到效果这么好」。但只在可验证域训练显然是个不满意的限制——他赌的是模型的 self-judging 能力（验证比生成简单）会逐步打开非可验证任务。

- **变心的一件事**：「我本来相信必须在很广的分布上训练才能让模型更强，但事实证明，只在数学和代码这种窄但难的点上训练，居然带来了显著泛化——这超出我的预期。」

- **AGI 是不是来了**：「如果让 7 年前的我用今天的模型，我大概率会直接说这就是 AGI。」差的只是「真正从经验中学习」这块拼图。
