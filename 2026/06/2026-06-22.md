### Anthropic Engineering — Scaling Managed Agents：把「大脑」和「双手」解耦
Anthropic 推出 **Managed Agents**：一个托管在 Claude Platform 上、替你运行长时程 agent 的服务。核心洞见是——harness（驱动 agent 的脚手架）编码了「Claude 自己做不到什么」的假设，而这些假设会随模型变强而过期。文中举例：他们曾给 Claude Sonnet 4.5 加了 context reset 来解决「上下文焦虑」（感觉接近上限就草草收尾），但换到 Opus 4.5 上这个行为消失了，reset 反而成了累赘。受操作系统「为尚未设想的程序设计」（process、file 等抽象比硬件更长寿，`read()` 不在乎你读的是 70 年代磁盘还是现代 SSD）的启发，他们把 agent 虚拟化成三个可独立替换的组件：**session**（只追加的事件日志）、**harness**（调用 Claude 并路由工具调用的循环）、**sandbox**（执行环境）。他们还反思了早期把三者塞进单一容器的「养宠物」式架构——容器一挂会话就丢、调试还会碰到用户数据，最终走向「牛群」式可替换设计。
🔗 https://www.anthropic.com/engineering/managed-agents

### Claude Blog — Managed Agents 新功能：自托管沙箱与 MCP 隧道

### Unsupervised Learning — AI Vibe Check：实验室混战、为什么 API 可能消失、以及未来预测
**核心结论：在算力极度紧缺的当下，最大胆的预测不是某个模型有多强，而是「前沿实验室的公开 API 可能会消失」——不是商业决策，而是被算力逼的。**

主持人 Jacob Efron 与两位嘉宾对谈：Datalogy 创始人 Ari（前 DeepMind、Meta 研究员）和 Radical Ventures 的 Rob。几个反直觉的判断值得记下：

- **开源权重模型可能整体掉队**。Rob 指出 Meta 在收缩开源战略，中国实验室（Qwen、DeepSeek 等）也开始把最强的模型藏在 API 后面、只开源更小更弱的版本。原因很现实：「服务这些开源模型却没有收入进账，实在太贵了。」两人都不认为开源模型存在可行的商业模式——开源只是打知名度的「营销」，一旦建立信誉就会转向卖托管推理。

- **API 可能因算力枯竭而消失**。Ari 抛出最辣的观点：不难想象 Anthropic 因算力受限到极致而直接砍掉 API，因为相比 API，他们显然更愿意把算力留给利润更高的 Claude Code。「实际上 API 消失，不是出于商业决策，而纯粹是算力约束。」OpenAI 已经开始卖「推理 token 期货」（保证未来的推理额度），这对所有在模型之上构建产品的公司都是生存级威胁。

- **算力紧缺至少持续到 2030**。真正的瓶颈在半导体供应链——全世界只有一家公司（TSMC）能造尖端芯片，而其最关键的设备只有一家（ASML）能造。Rob 介绍了试图绕过 EUV 物理极限的新方向：用原子束代替光的「原子光刻」，以及波长更短的「X 射线光刻」，但至少还要五年。AMD、Trainium、Cerebras 等非 NVIDIA 芯片不会增加总算力，但会在紧缺中吃到巨大红利。

- **效率将成为主线**。Ari 长期看好「不需要万亿参数也能达到前沿能力」——小模型持续追平一两年前的最大模型，紧缺会倒逼蒸馏、token 效率等方向的大量创新。他还提到 Opus 从 4.6 到 4.7 的 token 效率差异之大，让一些企业账单一夜翻倍，正催生强烈的降本需求。

关于 Fable 发布，Rob 的评价很冷静：「它既是、也不是什么大事」——它确实是一次有意义的 SOTA 进步，足以推翻「预训练撞墙」的叙事，但若三周后录这期，大概又会在聊另一家的新模型了。两人也提到 Anthropic 对 Fable 的「静默限制」（不给拒绝、只是悄悄做得差）惹恼了不少铁粉，可能反而把 Twitter 上最响亮的声音推向 Codex。
