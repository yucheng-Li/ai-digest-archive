**AI & I by Every — How Anthropic Uses Claude Fable 5 With Mike Krieger**

一句话 takeaway：当模型强到可以"托付一整夜的复杂任务"时，工程师的工作重心从"写代码"彻底转向"对齐意图 + 验证结果"。

Mike Krieger（Anthropic 实验室负责人、Instagram 联合创始人）分享了他用 Fable 5 两个月后的真实工作流，几个反直觉的点：

- **委托而非协作**：他常常"跟 Claude 道个晚安"，布置一个复杂任务让它跑通宵，凌晨两点就完成了。模型卡住时会自己搭脚手架、写文档、记下待办，等服务恢复再修——"像个可以放心托付大量工作的队友"。
- **先架构对齐，再让它执行**：他现在花大量时间在前期架构对话上，让 Claude 一键产出 HTML 页面或带图表的 markdown 给团队对齐，"逼出更早的对齐"。
- **验证是关键瓶颈**：他今年"完全转向了验证派"——给每个 PR 配截图/视频画廊，甚至给 Claude 喂 FFmpeg 让它逐帧看自己做的动画里有没有卡顿。"在第 8 张截图上那个 error，我从没真正见过，但能看出用户会怎么撞上它。"
- **效价判断力**：他最看重 Fable 的一点是它有"系统级"判断——会反过来提醒"你那个 feature flag 还没开吧""这改动会影响那边的 contract"，甚至在 code review 里有理有据地反驳 reviewer 而不是无脑认错。
- **软件工程没有结束，但变了**：他认为纯粹的"敲代码"craft 在消退，有些好工程师会有失落感，但"软件生产/开发"依然鲜活且必要，所有权（DRI）和对生产环境的理解仍是人的核心价值。
