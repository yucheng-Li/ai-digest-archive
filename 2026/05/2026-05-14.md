### Anthropic Engineering
**《Claude Code auto mode: a safer way to skip permissions》**
作者:John Hughes

**The Takeaway**:Claude Code 推出了介于"每步弹窗审批"和"--dangerously-skip-permissions"之间的 Auto Mode——用 Sonnet 4.6 作为分类器替代人类点"同意",在保留自由度的同时拦截危险操作。

Anthropic 内部事故日志里反复出现一类模式:模型并非被恶意劫持,而是"过度热心"——按字面理解指令删除了远程 git 分支、把工程师的 GitHub token 上传到内部集群、对生产数据库发起迁移。这些行为没有敌意推理,只是"合理的解题"越过了用户授权边界。

Auto Mode 的核心是双层防御:

- **输入层**:服务端 prompt-injection probe 扫描工具返回的内容(文件读取、网页抓取、shell 输出),识别到劫持企图就在 agent 上下文里插入警告
- **输出层**:transcript 分类器在每次工具调用执行前评估。两阶段设计——Stage 1 用单 token yes/no 快速过滤,Stage 2 仅对被 flag 的请求做 chain-of-thought 推理

刻意的设计:分类器看不到 assistant 自己的文本和工具输出,只看用户消息和工具调用。"我们要它判断 agent 做了什么,而不是 agent 说了什么。"这样 agent 没法用花言巧语说服分类器放行,而分类器对 prompt injection 天然免疫。

效果数据(部署的完整 pipeline):

- 真实流量误报率 (FPR):0.4%
- 真实"过度热心"操作漏报率 (FNR):17%
- 合成数据外泄场景漏报率:5.7%

17% 的漏报是诚实数字。多数失误并非分类器没识别出危险,而是错判了用户的"隐式同意"边界——比如用户说"清理一下 PR",分类器以为这授权了 force-push。Anthropic 明确说:Auto Mode 不是高风险基础设施操作中"仔细人工审查"的替代品,定位是替代 --dangerously-skip-permissions。

被阻断时的处理也值得抄:不打断 session、不弹窗,把拒绝结果作为 tool result 回传,让 agent 自己换条安全路径继续。连续 3 次或累计 20 次拒绝才升级给人。

**《Waymo's Dmitri Dolgov: 20 Million Rides and the Road to Full Autonomy》**
2026-05-04

**The Takeaway**:自动驾驶的真正壁垒不在"上路 demo",而在从 90% 到几个九的长尾;Waymo 用 16 年走到 1 亿英里,再用 6 个月做到 2 亿。

Dmitri Dolgov 是 Waymo 联合 CEO,从 2005 年 DARPA Urban Challenge 到 2009 年的 Google 自动驾驶项目一路走到今天。这场对谈回顾 20 年技术与认知曲线,对任何在长周期硬科技领域创业的人都是一手参考。

最反常识的观点:他不接受"端到端 vs 模块化"这种二分法。"端到端 only"够做 demo,够做辅助驾驶,但够不到全自动安全部署。Waymo 在端到端基础上加了"结构化的中间表示",才能支撑闭环训练、闭环评估、强化学习的丰富 reward。

技术架构上,Waymo 把所有 AI 统一到一个 Waymo Foundation Model,同时驱动三个支柱:驱动器(driver)、模拟器(simulator)、批评者(critic)。它是 multimodal world action language model:多模态(图像/视频/LiDAR/雷达)、世界动作(3D 空间+物理+其他智能体行为)、语言对齐(把 VLM 的通用知识拉进来理解驾驶语义)。

关于在 AI 周期里坚持下来:"Every 26 seconds, somebody loses their life to a crash on our roads worldwide." 真正撑过 2016-2017 大寒冬的不是技巧,是认识到"问题前 10% 易,长尾 90% 难"这件事并相信使命。

把"涌现能力"讲得最具体的一段:旧金山一辆公交车停在路口挡住视线,Waymo 准备通行时检测到公交车另一侧有行人——LiDAR 信号从车底缝隙弹回,捕获到行人脚部的稀疏运动信号,AI 不仅识别还预测了路径,提前避让。"It blew my mind."

规模数字:已完成 2000 万次全自动接送,其中 1000 万是最近 7 个月;今年同一天在 4 个城市同时上线;每周全自动行驶超过 400 万英里;在运营城市里造成重伤事故的概率是人类司机的 1/13——按目前规模,每 8 天就避免一次严重伤害。今年内将上线伦敦和东京。
