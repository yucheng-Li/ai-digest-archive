### AI & I by Every — 《Claude Code Can Be Your Second Brain》

**核心要点**：把 Claude Code 装进你的 Obsidian 笔记库，再扔到家里的迷你服务器上，你就拥有一个能从手机上调用的"第二大脑"——一个不写文章、只逼你思考的研究伙伴。

主角是 Noah Brier——前 Percolate / Variance 联合创始人，现在经营 AI 策略咨询公司 Alephic，同时主理 AI × 营销大会 brxnd.ai。他展示了一套相当反主流的 Claude Code 用法：**几乎不用它写代码，主要用来管笔记**。整套系统的关键拼图是：

- Obsidian 作为本地 markdown 知识库，用 Git 私有仓库同步；
- Claude Code 直接跑在整个 vault 根目录，访问全量笔记；
- 自建 **thinking-partner sub-agent**，配上死命令——"Noah 在收集材料时，绝不替他写任何东西，不要写大纲、不要写草稿"；
- 在家里地下室放一台 mini PC + Tailscale VPN + 终端 app Termius，于是手机也能跑 Claude Code，他朋友们都开始在他这台机器上开分区。

Noah 最锋利的几个洞见：

1. **大家叫这玩意儿 "generative" 是一种误导**——"模型的*阅读*能力比写作能力有用得多，我们日常产出 artifact 的频率，远低于我们思考的频率。"
2. 模型公司被"helpful assistant"这个 meme 拖住了，导致即使你明确说"别写"，它还是想替你写。要在 prompt 里把"do not create outlines, drafts, or any versions"写到近乎粗暴。
3. **AI 是反直觉的，没人有 intuition**——他职业生涯都在学怎么"按对方契约对接 API"，而 ChatGPT 插件第一次让他可以*自己*定义契约让大公司来对接，"和我所有的直觉 180 度相反"。所以那些觉得自己被甩下的人，其实根本没起跑，前面全是 white space。
4. 关于教育：英语老师真正的工作不是教孩子写作，而是说服他们"写作值得学"。AI 暴露的是教育体系本身的缺陷——为什么我们考试这么多、思考这么少？他正在 NYU 提一个新课《Code is Essay》。
5. 最爆的工作模式：早上送完孩子，他坐在咖啡馆里用手机跑了**两小时**真正意义上的"深度思考"，包括研究、笔记、push 代码 PR——"我还坐在池塘边没动。"

**最难忘的一句**："There's entirely too much focus on its ability to write and not enough focus on its ability to read."
