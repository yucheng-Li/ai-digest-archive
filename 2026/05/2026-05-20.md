### Anthropic Engineering — An update on recent Claude Code quality reports
Anthropic 公开做了一份事故复盘，承认过去一个月 Claude Code 体验下滑是真的，但根因不是模型本身退化（API 层面没问题），而是三个独立改动叠加形成的"广泛而不一致的退化"假象：
1. 3 月 4 日把 Claude Code 默认 reasoning effort 从 high 降到 medium，本意是缓解 UI 假死，但事后判定方向错了，4 月 7 日回滚（影响 Sonnet 4.6、Opus 4.6）。
2. 3 月 26 日上线"空闲 1 小时后清空旧 thinking 块"的优化，结果有 bug——会话剩下的每一轮都重复清空，导致 Claude 显得健忘又啰嗦，4 月 10 日修复。
3. 4 月 16 日加了一条"减少冗长"的 system prompt 指令，叠加其他改动后伤到了 coding 质量，4 月 20 日回滚（影响 Sonnet 4.6、Opus 4.6、Opus 4.7）。

文中关键反思:"This isn't the experience users should expect from Claude Code." 作为补偿，4 月 23 日所有订阅用户的用量上限被重置。Anthropic 承认问题最早 3 月初就有反馈，但当时和正常波动难以区分，内部 eval 也没复现出来。 https://www.anthropic.com/engineering/april-23-postmortem

### Claude Blog — Built-in memory for Claude Managed Agents
Claude Managed Agents 的 memory 层进入 public beta。亮点是 memory 直接挂到文件系统上，Claude 可以用熟悉的 bash 和 code execution 操作它，写出来的 memory 更结构化、更克制。企业向的能力配齐了：scoped permissions、audit log、API 全程序化管理、可导出可回滚、可在多个 agent 间共享存储（org-wide read-only + per-user read-write 这类模式）。三个落地案例值得记一笔：Netflix 用它跨 session 携带上下文和人类的中途修正；Rakuten 长跑 agent 通过 memory 让"重复犯错率"降了 97%；Wisedocs 的文档校验流水线靠跨 session memory 把验证速度提了 30%。 https://claude.com/blog/claude-managed-agents-memory

### AI & I by Every — The Secrets of Claude's Platform From the Team Who Built It
**核心结论：** 一年后 Anthropic 想让 Claude 平台压缩到"两个参数：outcome + budget"——其余的模型选择、harness 架构、子 agent 编排都由 Claude 自己决定。

Anthropic 平台的产品负责人 Angela 和工程负责人 Caitlin（两人原 Stripe 出身）解释了为什么 Claude Managed Agents 不是又一个 SDK，而是 Anthropic 自己造的 agent 基础设施开放出来。Angela 抛出一个反共识判断：过去几个月 agent 圈流行"做一个超通用 harness 然后热插各家模型"，但下一代模型时代这套就崩了——各家路径开始分叉（Anthropic 重 file system + skills，OpenAI 走另一种），所谓"热插换"的最小单元会从"模型"上升到"harness + 模型"打包成的 agent。

Caitlin 给了一个反直觉的客户洞察："人们以为难的是 harness engineering，结果真正撞墙的是基础设施。"原型很快——拿 claude -p、agent SDK 都能跑起来；可一旦要 productionize、要 sandbox 长期不掉线、要存 transcript、要 spin up/down，所有人都死在同一堵墙上。Managed Agents 就是 Anthropic 自己反复造完这套基础设施之后，决定"再做一次，做对，然后开放"。

她们也给了多 agent 编排的实战 taxonomy：advisor 策略（拆分执行和建议）、adversarial 模式（一个生成、一个挑刺）、并行碎片再合并、best-of-N——每种适配的场景不同，比如 wide research 适合一种、bug hunting 适合另一种。

最值得记的一段是 Angela 对衡量 agent 成功的看法："最终一切都该压缩到 outcome 加 budget，剩下的应该被算法解出来。"——这是 Anthropic 看 platform 终局的"两参数哲学"。
