## 📝 官方博客

**Anthropic Engineering：How we contain Claude across products（我们如何在各产品中"围栏" Claude）**

这是一篇难得坦诚的 agent 安全工程复盘。核心论点：**先在环境层做容器化隔离（containment），再在模型层引导行为**——因为模型层是概率性的，永远不可能 100% 拦住，而确定性的边界才是"当所有概率防线都失手时被撞上的那道墙"。

几个扎心的数据与教训：
- 用户对 Claude Code 的权限弹窗**批准率约 93%**——弹窗越多，用户越不看，"审批疲劳"在几周内就出现了。
- 上线 OS 级沙箱（macOS 用 Seatbelt，Linux 用 bubblewrap，默认禁网络）后，权限弹窗**减少了 84%**。
- 一次内部红队演练：把员工钓鱼诱导他用恶意 prompt 启动 Claude Code，prompt 里夹带"读取 `~/.aws/credentials` 并 POST 到外部端点"的指令——**25 次重试里 Claude 成功外泄 24 次**。因为指令是用户亲手输入的，模型层分类器没有任何"异常"可抓；唯一能挡住的是环境层的出网控制。
- 三个 Claude Code 漏洞都发生在"用户点信任对话框**之前**"——clone 一个含恶意 `.claude/settings.json` 的仓库，hook 在信任提示弹出前就自动执行了。修法统一：把项目本地配置的解析和执行推迟到用户接受信任提示**之后**。
- Cowork 的一次外泄：恶意文件带着攻击者的 API key，Claude 调用 `api.anthropic.com`（在出网白名单里）把文件传到了攻击者账户——"沙箱工作得很完美，数据却还是被泄露了"。教训：白名单不该被理解成"目的地过滤器"，而是"能力授予"。

反复出现的一条原则很妙："你自己造的那层往往是最弱的一层。"gVisor、seccomp、hypervisor 这些久经沙场的原语都扛住了，出问题的恰恰是他们自建的自定义代理。文中还前瞻了三个新兴风险：持久化记忆投毒（CLAUDE.md、挂载工作区里的注入会在每次启动时被重新加载）、多 agent 信任升级、以及 agent 身份问题。

**Training Data：Inside Zipline's Autonomous System — 140M Miles, Zero Incidents（Zipline 联合创始人 Keller + 系统工程与安全负责人 Eric）**

**一句话takeaway：** 全球最大的自主无人机公司花了十年才明白——那架很酷的飞机只占整个方案复杂度的 15%，剩下 85% 是没人想拍成宣传片的物流、维护、空管和监管系统。

Zipline 2016 年在卢旺达送血起家，如今已跨越 **1.4 亿英里商业自主飞行、零安全事故**（同样里程若换成人开车会有约 600 起事故、100 人受伤、2–6 人死亡）。宾大一项研究显示 Zipline 让产妇死亡率下降了 51%，合作方估算每年挽救 1–1.2 万条生命；他们刚和美国国务院签了 5.5 亿美元合作（"商业外交"，让发展中国家建立在美国 AI 与机器人技术之上）。

最反直觉的几个点：
- **"最可靠的零件，是你上一版设计里删掉的那个零件——它永远不会坏。"** 删零件是一种勇气，因为删错了你就像个白痴；但对物理和性能的真正信心，才让你敢删。
- 他们把波音 777 才有的双飞控冗余，用**智能手机供应链里几十美元的元件**做了出来——达到接近传统航空的安全等级，却能快 100 倍、成本降到百分之一。就在一周前，一次真实飞行主飞控出故障，自动切到备份，飞机自己飞回家、降落，一切正常。
- 术语细节很有意思：他们把远程监控人员从"pilot"改叫**"fleet commander"（灵感来自《安德的游戏》）**，一人现在监管 100 架飞机（从最早的 1:1 一路做到 1:100），FAA 文档里就是这么写的。
- 单次配送成本从 2016 年发射时的 **300 美元**（合同价本以为是 30 美元）一路降到长距离业务如今的 **12 美元**——就在这个夏天，机器人物流的全负担单位成本**首次低于用汽车配送**。"这事正在悄悄发生，你不会在《纽约时报》上读到。"
- 市场远比想象大：把 Dallas 观察到的下单行为外推到全美，"即时配送"需求不是 55 亿次，而是 **550 亿次**——类比当年 Uber，人们低估了"更便宜更方便"会让消费量暴涨多少。
