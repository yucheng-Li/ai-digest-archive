**Thibault Sottiaux（OpenAI，负责 Codex 与 ChatGPT）** 今天发了今日最大的一条：他给所有 ChatGPT Work 和 Codex 用户**重置了用量额度**，并第一次详细解释了 GPT-5.6 Sol 为什么烧额度这么快。他明确否认"偷偷降配额"：真实原因是 Sol 更愿意长时间干活、发起更多 tool call、跨工具和 subagent 协调复杂流程；同样的 reasoning effort 下 Sol 比上一代更"用力"，High on Sol 消耗的 token 比 GPT-5.5 的 High 更多；programmatic tool calling（code mode）让它能并行调用、边等边干，副作用是每轮响应数、缓存输入 token 都上去了。经过几轮优化，典型使用场景下额度预计能多撑约 **18%**，暂停调查期间取消的 5 小时窗口限制明天恢复。他还坦承了一个方法论错误：**发布前只盯了平均值和中位数，漏掉了长尾**——中位数用户其实觉得 Sol 挺省 token，但啃硬任务的重度用户额度掉得飞快。"We should have recognized this sooner and been more upfront about it." 同日他还开源了一套**安全漏洞扫描的 CLI + TypeScript SDK**，能扫仓库、review 改动、追踪历史 finding，可以挂进 CI。
