**Anthropic Engineering：An update on recent Claude Code quality reports**
Anthropic 复盘了过去一个月「Claude Code 变笨了」的用户反馈，把问题追溯到三个独立改动（API 层未受影响，均已在 4 月 20 日 v2.1.116 修复）：① 3 月 4 日把默认 reasoning effort 从 high 降到 medium 以减少延迟，被证明是错误权衡，4 月 7 日回滚——现在 Opus 4.7 默认 xhigh，其余模型默认 high；② 3 月 26 日一个缓存优化本应只在会话闲置超 1 小时时清理一次旧的 thinking，但 bug 导致它此后每一轮都清理，让 Claude 显得健忘、重复、工具选择怪异，还导致用量额度异常消耗，4 月 10 日修复；③ 4 月 16 日为降低啰嗦度加的 system prompt（「工具调用间文本 ≤25 词，最终回复 ≤100 词」）意外拉低了编码智能，4 月 20 日回滚。值得注意的是，Anthropic 用 Opus 4.7 回测了引入 bug 的 PR，Opus 4.7 找到了这个 bug 而 Opus 4.6 没有。Anthropic 宣布为所有订阅用户重置用量额度。

**Anthropic Engineering：Scaling Managed Agents: Decoupling the brain from the hands**
Anthropic 发布了 Managed Agents——一个托管的长时程 agent 服务，核心设计是把 agent 拆成三个可独立失败、可独立替换的接口：session（记录一切发生事件的只读追加日志）、harness（调用 Claude 并路由工具调用的循环）、sandbox（执行代码的环境）。文章用「宠物 vs 牲畜」的比喻讲了为什么最初把三者塞进一个容器是错的——容器一挂 session 就丢，成了得精心照料的「宠物」。解耦「大脑」（Claude + harness）和「双手」（sandbox + 工具）后，容器变成可随时重建的「牲畜」，harness 通过 `execute(name, input) → string` 像调用任何工具一样调用容器。安全上，凭证永远不进入沙箱（Git 用仓库 token 在初始化时 clone 好，MCP 用独立 proxy 从 vault 取凭证）。这套架构让 p50 TTFT（首 token 延迟）下降约 60%，p95 下降超 90%。
https://www.anthropic.com/engineering/managed-agents

**Claude Blog：New in Claude Managed Agents: self-hosted sandboxes and MCP tunnels**
Managed Agents 新增两大能力：① 自托管沙箱（公测）——agent 执行工具的沙箱可以跑在你自己的基础设施上，或用 Cloudflare、Daytona、Modal、Vercel 等托管方；agent 编排循环仍留在 Anthropic 侧，但工具执行搬进你的环境，文件和仓库不出你的边界，算力大小和运行镜像都由你控制。② MCP tunnels（研究预览）——你的 agent 可以在不把 MCP server 暴露到公网的前提下访问私有网络内的服务（内部数据库、私有 API、知识库、工单系统），只需部署一个轻量网关发起单向出站连接，无需入站防火墙规则，流量端到端加密。Amplitude、Clay、Rogo 等公司已在这套组合上构建各自的 agent。

**No Priors：Re-engineering the Semiconductor Supply Chain with Intel CEO Lip-Bu Tan**

**核心要点**：一位 66 岁的传奇半导体投资人接手了行业里最难的工作——把 Intel 从「老旧的电子表格公司」重塑成移动迅速的 AI 平台公司，而他的打法是「先爬、再走、最后冲刺」。

Lip-Bu Tan 从 Walden 的传奇投资人做到 Cadence CEO（十三年，为股东带来约 76 倍回报），如今掌舵 Intel。他坦言这是「行业里最难的工作」，上任 14 个月里最意外的一课，是特朗普总统某天清晨要求他因利益冲突辞职——他花了一个周末说服自己「我不需要这份工作，我做纯粹是为了救 Intel」，把个人得失放到一边，最终争取到了解释和留任的机会。

他的救援逻辑非常具体：先强化资产负债表（美国政府成为大股东、老友黄仁勋投的 50 亿美元现已变成 250 亿、软银也伸出援手），再聚焦并精简产品线。一个反直觉的行业信号是 CPU 的翻身——「过去训练场景是 1 个 CPU 配 8 个 GPU，现在我看到 1 比 4，甚至可能 1 比 1」，因为在强化学习和编排海量 agent 的场景里，CPU 反而更合适。

对于摩尔定律的物理极限，他的答案是材料科学：投资氮化镓、碳化硅、磷化铟三种新材料，用玻璃和人造钻石做散热封装。他还给出了对十年后赢家的判断：「激光聚焦于一个细分领域、找到对的合作伙伴、并能把公司规模化」，无论是 Jensen 那样把 CUDA 做成平台的大公司，还是 Anthropic、OpenAI 那样用更优雅的方式改变游戏规则的初创公司。

他最打动人的一句话，是对创业本质的总结：「我投的 10 家公司里有 9 家在半路上改了商业计划，因为市场变了。所以我喜欢有一支创业团队，而不只是一个人。」
