## PODCASTS

**Training Data —《Anthropic's Katelyn Lesse & Angela Jiang: Building an Ecosystem, not a Walled Garden》**

**核心 takeaway：** Anthropic 正把平台从"知识层"往"执行层"、再往"协调层"推进，下一个真正的 alpha 不在压榨 prompt caching 这类底层 harness，而在更高一层的"strategies / meta-harness"——给每个 token 分配不同的"工作"。

负责 Anthropic Platform 的 Angela Jiang 和 Katelyn（Caitlin）Lesse 把平台抽象拆成"三层蛋糕"：最底是**知识层**（Messages API、skills、memory，让模型知道怎么做事）；中间是**执行层**（低阶 harness + 托管基础设施，产品即 Claude Managed Agents，帮你搞定 sandbox 治理、session 存储续跑这些又难又无聊的活）；最上是刚开始成形的**协调层**。

最反直觉的一点是他们对"harness 竞争"的判断：随着模型越来越可被 steer，过去那种"砌两堵墙逼模型走直线"的脚手架该删就删——"模型能消化掉一部分脚手架"。真正值得自己掌控的，是"验证逻辑"（尤其 legal、finance 这类容错极低的领域）和更高阶的 token 预算分配策略。Katelyn 直言底层最佳实践其实很朴素："prompt caching，做就对了，能省一大笔钱"。

关于 Claude Tag（Slack 里的 Claude）被吐槽"不就是个 Slack bot"，Angela 的回应很到位：重点从来不是那个 @ 的界面，而是水面下那座冰山般的 context engineering 和架构——"它应该就像一个同事"。她引用 Andrej Karpathy 的说法称之为"组织级 harness"。

关于成本，她给出的框架是：别因为贵就掐掉 AI 使用（很多公司靠 shadow IT 让 Claude Code 铺开），而要设计一个"路由器"——按任务复杂度把难活派给大模型、简单活派给便宜模型。金句："如果它给你想要的回报又很难做到，我们就去把它做简单，让你能真正跑起你需要的实验。"
