## OFFICIAL BLOGS

**Claude Blog — Building intelligent apps for Apple platforms with Claude in the Foundation Models framework**
Anthropic 发布了一个新的 Swift package，让苹果开发者能通过 Apple 的 Foundation Models framework 直接调用 Claude。玩法是分工：本地端用苹果的 on-device 模型做总结、抽取这类快速任务，一旦请求需要多步推理、代码生成等重活，就无缝交接给 Claude，Claude 还能联网搜实时信息、执行代码做数据分析。关键的工程红利在于——苹果框架通过 `@Generable` 注解返回强类型的 Swift 值，所以到达 Claude API 调用时拿到的是干净的结构化输入，而不是原始用户文本，package 会自动处理 streaming、tool call 和把结构化结果回传到 SwiftUI 视图。支持 iOS 27 / iPadOS 27 / macOS 27 / visionOS 27 / watchOS 27，只需加入项目、用 Anthropic API key 登录即可。
🔗 https://claude.com/blog/claude-for-foundation-models

**The MAD Podcast with Matt Turck — Cloudflare CEO: The Internet's Business Model Is Dead**
**核心结论**：互联网过去 28 年靠广告支撑的商业模式正在崩塌，因为「机器人不点广告」。

Cloudflare 联合创始人兼 CEO Matthew Prince 抛出一个里程碑式的数据：2026 年上半年，互联网上的 bot 流量首次超过了人类流量。而他打赌未来五年 bot 流量会是人类流量的 **1000 倍**。原因是 agent 的行为方式和人完全不同——「我自己挑一台数码相机可能只看 5 个网站，但我的 agent 可能会访问 5000 个」。

他直言 bot、crawler、agent 其实是同一个东西，只是「你想说好话就叫 agent，想说难听点就叫爬虫」。这带来两个连锁反应：一是基础设施需求爆炸（他类比 COVID 期间两周内流量翻倍，「很快那会显得小儿科」）；二是商业模式必须重构——「未来五年互联网的商业模式会剧变，而它会变成什么，现在完全没有定义。」他还抛出一个耐人寻味的问题：在 agentic 世界里，「品牌」还意味着什么?毕竟 bot 有无限的耐心去逐一发掘一切，人类靠 logo 做认知捷径的那套逻辑将不再成立。

> "Over the next five years, the business model of the Internet is gonna change radically."
