## 📝 官方博客

**Claude Blog — 用 Foundation Models framework 在 Apple 平台上构建智能应用**
Anthropic 发布了一个 Swift 包，让 Apple 开发者可以通过 Apple 的 Foundation Models framework 调用 Claude。思路是分工协作：本地端用 Apple 的设备端模型做摘要、抽取等快速任务，一旦需要多步推理、代码生成、联网搜索或执行代码做数据分析，就无缝交给 Claude。因为 Apple 框架会通过 `@Generable` 注解返回类型化的 Swift 值，开发者到调用 Claude API 时拿到的是干净的结构化输入而非原始用户文本。该包处理流式返回、工具调用和结构化响应回填到 SwiftUI 视图。支持 iOS 27 / iPadOS 27 / macOS 27 / visionOS 27 / watchOS 27。
🔗 https://claude.com/blog/claude-for-foundation-models

## 🎙️ 播客

**Training Data — Factory 创始人 Matan Grinberg：即将到来的"黑灯工厂"，软件自己造软件**

**一句话 takeaway：** 未来 12–24 个月，90% 的 token 将是"异步 token"——由 agent 自主发起，而非人类逐条敲命令；软件开发正走向"关灯也照跑"的黑灯工厂。

Factory 做的是面向企业的自主编程 agent（"droids"）。Matan 三年半前（2023 年 4 月）就 all-in 全自主 agent，比市场早了两年——他的名言是"**早两三年，等于错了**（being two or three years early is the same as being wrong）"。最难的时刻，他们在产品还不够好、已做到近 200 万美元营收时，主动把钱退还给客户，为的是保住信任："我们的工作是造出好到让客户自己对我们上瘾的东西。"

几个反直觉的判断：
- **企业最在乎的不是最强模型，而是"模型独立性"**——不想被任何一家模型厂锁死，都被云时代的续约涨价坑怕了。Factory 靠 router 做到可热插拔换模型。
- **不要模型与 harness 协同设计。** 支持多模型的 harness 反而更强："what data is to a model, models are to a harness"——模型之于 harness，就像数据之于模型，见得多才不过拟合。
- **开源模型正逼近"frontier 减一"。** 他盛赞 GLM 5.2，说 Factory 内部已不设 token 限额、一半 token 走开源模型；开源模型不该跟 OPUS 4.8 / GPT 5.6 比，而该跟 OPUS 4.7 / GPT 5.5 比。开源 token 占比从年初的不到 1% → Q1 个位数 → 现已跨入两位数百分比。
- **从 token maxing 到成本理性化。** 银行客户每月花几十万美元让人用 Opus 问"今天天气如何"；未来每个 CIO 都要为"每一块钱该投人头还是投 token、投到组织哪个环节"给出答案。
