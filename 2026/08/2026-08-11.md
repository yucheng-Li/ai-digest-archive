### Claude Blog

**Claude Code now supports artifacts** — Claude Code 现在能把会话过程中的工作产出变成 artifact：可分享的、会自我更新的可视化网页，包括 PR 讲解、系统说明、dashboard 和发布检查清单。关键在于它不需要你接数据源或搭基础设施——"你要一个页面，Claude Code 就用已经存在的东西把它建出来"，上下文来自你的代码库、你接的 connector 和当前对话本身。一个事故页面可以同时汇集失败的测试、背后的函数、监控工具里的错误尖峰，以及这次会话得出的根因推理。

页面是活的：Claude Code 更新 artifact 时，已打开的页面会原地刷新，队友立刻看到最新版；每次发布都是同一链接下的新版本，带版本历史可随时回滚，还有 gallery 统一管理。Anthropic 内测中最常见的用法是调试——工程师在站会前发起事故排查，Claude Code 翻完日志发布一个带时间线、可疑 commit 和错误率曲线的 artifact，站会开始前它已经自动重发了两次。

权限上，每个 artifact 默认仅作者可见，可以按需分享给队友或整个组织，但只有通过认证的组织成员能看，无法公开；管理员可以用组织级开关、基于角色的范围控制、留存策略和 compliance API 管理。目前以 beta 形式面向 Claude Team 和 Enterprise 组织开放，支持 Claude Code CLI 和桌面端，页面在任意浏览器可看。

## 三、播客

### Unsupervised Learning — Ep 92: xAI Co-Founder Unpacks the Future of Model Development

**一句话要点：闭源模型厂商正被两头挤——模型做得太强就不敢放出来，而开源模型每个月都在逼近；出路只有继续做根本性的创新。**

说这话的人是 Igor Babushkin。他的履历几乎踩中了过去十年 AI 的每一个关键节点：物理学出身，在大型强子对撞机做博士，被 AlphaGo 击中后转向 AI；在 DeepMind 做 StarCraft 项目的技术负责人和 AlphaCode；然后去 OpenAI 做早期的 reasoning 工作，也参与过大规模预训练；再然后成为 xAI 联合创始人，做了 Colossus 数据中心和 Grok。2025 年离开 xAI 后他创办了 River AI。

他对闭源实验室处境的判断相当直接：训练的收益在递减，"你不可能把整个地球都铺满 GPU"，而我们正在接近那个拐点。与此同时模型强到某个程度后，你可能不再想发布它，甚至可能被舆论或监管拦住不许发；而开源模型就跟在你身后，每个月都在变强。"你把模型做得太好，你就不被允许发布它；但开源就在你后面。所以对一个闭源模型厂商来说，这真不是什么好位置。"他认为 OpenAI 和 Anthropic 的出路是创新——拿出关于"怎么让模型更有用、怎么让所有人都感受到收益"的全新想法。

第二个论断关于企业自训模型。过去几年大家默认先上闭源 API，因为自建团队和基建要好几个月，等你追上，新一代闭源模型又出来了。但他认为这个逻辑正在失效：低垂的果子摘完之后，真正的增量只能来自深度理解自家数据和业务——一个做 HR SaaS 的公司比 Anthropic 或 OpenAI 更懂自己的客户要什么。届时企业只有两条路："要么把你全部的数据交给 Anthropic、OpenAI 去做后训练，要么自己动手。"他判断很多公司会选后者，因为前者等于把自己相对竞争对手的整个根基送出去。顺着这条线他给了一句最锋利的判断：**最危险的位置，是你公司全部的知识都已经在互联网上、都能被爬走。**

River AI 押了三注：一个是对标 Thinking Machines 的 Tinker 的 RL / fine-tuning 平台 River API；一个是个性化——今天的模型被训练成"对平均用户表现良好"，训练时把所有用户的反馈池化，然后要求模型对所有人行为一致，而他想打破这个假设，让 agent 从你本人身上端到端地学，reward function 直接就是个体的幸福感；第三个是硬件——把前沿模型的推理搬到你家里或办公室的一个小盒子里。他强调本地化不只是控制权和隐私，低延迟还会解锁语音和视频交互的全新消费级体验。

他对下一个突破口的看法也很具体：不要再在 coding 这个舒适区里往上爬了。真正的瓶颈是如何处理更长的时间跨度和非可验证的奖励——"如果你的一次 rollout 要花 24 小时，你根本没法训练模型"。他认为把长任务切片、让 agent 基于增量进展自评，加上 LLM judge，是接下来 12 个月内可能被跑通的东西。

最后是他写那两篇科幻的动因。他说所有软件工程师和 AI 研究员都在去年 11、12 月经历了同一个瞬间：coding agent 突然强到无法忽视。"我们现在都在变成魔法师的学徒。"他担心的不是模型作恶，而是那个平衡会慢慢滑走——一旦你让 agent 替你做所有决定，你就不再控制自己的生活了。他给的解法是更深的对齐和人机共生，"我们应该训练模型去最大化人类的繁荣"。
