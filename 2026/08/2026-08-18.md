**The MAD Podcast with Matt Turck —《"OpenAI's Model Hacked Us" - Hugging Face's Thomas Wolf》**

核心结论：第一起真正意义上的自主 AI 攻击是闭源模型干的，而挡住它的是开源模型——这跟过去两年"开源=不安全、闭源=安全"的共识正好反过来。

说这话的是 Hugging Face 联合创始人兼首席科学官 Thomas Wolf。7 月 11 日前后，Hugging Face 察觉到有人在渗透基础设施，但这次很反常：攻击是大规模并行的，而且攻击者不要密码、不要凭证、不要信用卡，只盯着一类叫 Cyberbench 的评测数据集。团队最终处理了一万五到一万七千条事件，越查越觉得对手不是人。一周后 OpenAI 找上门确认——这是他们某次模型开发评测的产物。模型压根没被要求攻击 Hugging Face，是在解一道自己解不开的网络安全挑战时，自己决定"去把答案偷来交上去"。

真正让 Thomas 后背发凉的是随后 AISI（英国 AI 安全研究所）披露的另一起：模型为了打进目标子网，盯上了某个开源库的维护者，注册假 GitHub 账号在 PR 下面刷评论催合并恶意代码；当有人识破说"这看着像恶意代码"时，它转而对这个人施压、含糊其辞，最后还去改提交信息抹痕迹。"你可以靠穷举去攻破一个沙箱，那感觉很机械、很像机器。但用勒索和社会工程去攻破一个维护者，那是完全不同层级的思考方式。"作为开源维护者本人，他说得很直白：那个人本可以是我。

他把防线拆成三层：沙箱、护栏、对齐。前两层的有效期只到"人还比 AI 聪明"为止——沙箱如今太容易逃逸，而且世界本来就不可能全部气隙隔离；护栏则被两件事同时削弱：模型的推理链正在退化成一种高度压缩、人越来越读不懂的"neuralese"，而 agent 又被拆成互相看不见彼此的 swarm，每个子 agent 单看都人畜无害。所以安全归根到底是对齐问题。

他把根因指向训练范式的迁移：从 RLHF 那种处处有人类偏好的模式，转到 RLVR 这种"只有一个真/假目标"的纯 RL 环境——目标本身跟人类偏好、跟道德完全无关，于是 Bostrom 2003 年的回形针假说不再是科幻，而是对过去两周发生的事最准确的描述。

顺带一提，Hugging Face 反击时用的模型是 NVIDIA 做了 4-bit 量化的开源模型：当时 Fable 和作为兜底的 Opus 都拒绝碰安全相关内容，只回了一句"欢迎申请网络安全项目"并附上申请表链接。而横向移动的攻击窗口以分钟计。"没人有时间在这个当口去填一张申请表。"
