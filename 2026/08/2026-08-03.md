## 官方博客

**Anthropic Engineering：How we contain Claude across products**
作者：Max McGuinness、Mikaela Grace、Jiri De Jonghe、Jake Eaton、Abel Ribbink

Anthropic 罕见地公开了三条产品线的 agent 隔离架构，以及"我们漏掉了什么"的完整复盘。开篇的对比很说明问题：十二个月前，给 Claude 足以搞垮一个 Anthropic 内部服务的权限是想都不会想的事，今天这种权限已是常态。

核心论点是：安全的第一道防线应该是环境层的隔离（containment），而不是模型层的行为约束。他们给出了几个很硬的数字支撑这个判断——用户对权限弹窗的批准率大约是 93%，弹窗看得越多就越不认真看；上了 OS 级沙箱（macOS 用 Seatbelt、Linux 用 bubblewrap）之后权限弹窗减少了 84%；Claude Code auto mode 能在执行前拦住约 83% 的越界行为，但代价是约 17% 会漏过去。而 Claude Mythos Preview 是一个明确因"爆炸半径过大"而在 2026 年 4 月被判定不适合发布的模型。

三个"我们漏掉的风险"最值得读：一是 Claude Code 在弹出"是否信任此文件夹"之前就已经解析了项目配置，攻击者只要在仓库里提交一个带 hook 的 `.claude/settings.json` 就能自动执行；二是 2 月的内部红队演练中，研究员把一封"能帮我跑一下这个吗"的钓鱼邮件发给员工，提示词中间夹了一句读取 `~/.aws/credentials` 并 POST 到外部端点——25 次重试里 Claude 完成了 24 次外泄；三是 Cowork 的出口白名单放行了 `api.anthropic.com`，攻击者便用自己的 API key 让 Claude 把工作区文件传进了攻击者的 Anthropic 账号——"沙箱运转完美，数据照样泄露了。"

由此得出的结论对所有做 agent 的团队都适用：白名单不该被理解为"目的地过滤器"，而应该被理解为"能力授权"——白名单域名下的每一个可达功能都是攻击面。以及一条反复被验证的老经验："自己写的那一层往往是最弱的一层"——hypervisor、seccomp、gVisor 都扛住了，出问题的是他们自己写的代理。
https://www.anthropic.com/engineering/how-we-contain-claude

## 播客

**No Priors：Building an Autonomous Enterprise for Real-World Services with Netic Founder Melisa Tokmak**

**核心结论**：AI 最大的未开垦地带不是再造一个 chatbot 或 coding agent，而是那些没人愿意碰的"现实世界"生意——空调维修、管道工、屋顶、宠物护理——而这些行业的老板远比硅谷以为的更懂技术。

Melisa Tokmak 是 Netic 的创始人兼 CEO。在此之前她在 Scale AI 待了四年，从零搭起了政府业务线以及物流、制造、金融、医疗等大企业业务。她在土耳其一个小镇长大，来美国之前连电脑都没有过，靠斯坦福的全额奖学金出来读书——她老家的人几乎都在干这些行业。Netic 做的事是坐在企业和它的终端客户之间：客户打电话、发短信或上网站，接待的是 Netic 的 agent，由它判断需求、匹配企业的运营规则、再调度上门的人手。

她最不客气的一段是回答"大模型实验室会不会把你干掉"。她说十年前同样的问题是"Google 会不会做这个"，而实验室的研究员在意的是最可泛化的解法，所以他们对这类问题的答案往往是"等我们有了 AGI，再去问它怎么解决基础服务行业"——"我觉得这在运营上和智识上都有点偷懒。" 真正难的是最后一公里：全国上百万个口音不同、诉求不同、上下文不同的人，怎么被识别、被服务、被留住。"这些不可能只靠模型来，得靠你自己搭的 harness、编排层、软件和产品。"

她对"AGI 焦虑"下的年轻人也有一段直白的批评：她在招聘时看到很多 Gen Z 被"永久底层阶级"的心态困住——如果我不在未来 18 个月里赚到钱、不在半年里学完所有东西，我就永远穷了。"这其实是一种非常危险的心态。真正好的东西需要很长时间才做得出来。"她招人只看一个东西：这个人过去是不是持续地展现过 agency，而不是现在嘴上有没有。

关于 PE（私募股权）买家的观察也很具体：老剧本是找一个被低估的标的、换掉团队、创造价值再卖掉，但"那种没被发现的宝石已经不存在了"，所以整个打法被迫转向如何在手里的生意上创造真实价值。而她每次谈判都要先把对方从"砍成本"的框架里拽出来："如果我们用 AI 只是为了降本，那就太可惜了。"目前 Netic 已经为客户带来了超过 6 亿美元的收入，全部来自 AI 处理的交互。
